# Unslop Design Direction: Chethan Kumar Engineering Portfolio

Derived specifically from Chethan Kumar's real engineering work, codebase reality, and target audience (senior technical recruiters, engineering directors, and systems architects).

---

## 1. Product
A disciplined, high-density personal engineering portfolio demonstrating verified technical execution across distributed systems, client-side cryptography, and applied machine learning for senior engineering hiring teams.

## 2. Character
**Precise, analytical, grounded.**
Zero synthetic hype, no inflated percentages, and no decorative gimmickry. Every claim is rooted in inspectable GitHub commits, test files, and runtime architectures.

## 3. World
**The Systems Engineer’s Workbench.**
Precision instruments, cryptographic telemetry terminals, architecture schematics, hardware-accelerated computation monitors, and technical notebooks. A dark graphite environment with soft white typography, crisp hairline dividers, and muted sage verification accents.

## 4. Visual Moments
- **Hero Moment (Home)**: An authentic, interactive **Cryptographic & Telemetry Systems Workbench** visually demonstrating client-side AES-256-GCM encryption streams, sub-45ms WebSocket state synchronisation, and PyTorch CUDA tensor telemetry.
- **Project Moments (Work)**: Genuine, high-fidelity architecture diagrams and verified system schematics directly extracted from the implementations of **SecretSnap** (zero-knowledge ephemeral messaging), **PRISM** (real-time telemetry and risk modeling), and **SpellSense** (NLP dynamic programming distance matrix).
- **Evidence Moment (Evidence)**: An interactive, verified codebase matrix directly cross-referencing technologies with repository entry points, test suites, and commit SHA proofs.

## 5. Signature Detail
**The Muted Sage Verification Hash (`#A8B8A7`)**:
A restrained hairline provenance stamp (`git:sha-256` / `verified:layer`) that marks verified technical evidence, linking a capability directly to its underlying repository proof. Used sparingly and with mathematical purpose.
